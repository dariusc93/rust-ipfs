# AI policy

AI tools are welcome in this project, but their output can contain mistakes or bias. You are responsible for reviewing
and understanding the work you submit, regardless of how it was written.

## Pull request summaries and descriptions

Every pull request must have a clear summary and description of what changed and why. Write naturally, as you would when
explaining your work to another person. Use your own words where possible. Focus on the key changes and keep the detail
appropriate to the size of the change.

If AI helps draft the description, review and edit it so it reflects your own understanding. Avoid generic wording,
filler, repeated points, and excessive detail.

## Understanding the code

You must understand all code you submit, including code generated or suggested by AI. Be ready to explain how it works
and why you chose the approach in your own words, without using AI to answer for you.

## Disclosing AI use

If you use AI for your contribution, say so in the pull request description. Name the tool, such as Codex, Claude, or
Copilot, and briefly explain how it helped. This includes writing or editing code, helping with code decisions, and
drafting or translating text. A short note is enough.

For example, you could write the following.

> I used Codex to help write the routing change. I reviewed the code and can
> explain how it works.

## Translation

You may use AI to translate from your native language into English. If you do, state that AI was used for the
translation and include both the original text and the English translation in the same pull request description or
comment. Clearly label each version. Your original text and the English translation are enough.

## Review

Maintainers may close pull requests that do not follow this policy, including when the author cannot explain the
submitted code without AI assistance.

For a serious security issue or urgent bug, a maintainer may take over a contribution that the author cannot explain.
The maintainer must understand, review, and verify the fix before merging it, and give credit to the original author.
AI use must still be disclosed.
